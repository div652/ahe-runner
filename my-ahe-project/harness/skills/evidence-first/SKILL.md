# Evidence-first procedure

1. State the requested outcome in one sentence.
2. Inspect the most direct available source before making an inference.
3. Record important confirmed facts with `record_note`.
4. Mark missing information explicitly instead of inventing a default.
5. Perform the smallest check that directly tests the requested outcome.
6. If the check fails, revise the approach and preserve the failure evidence.
7. Report completion only when the final observation supports it.

Keep notes reusable and task-general. Do not store benchmark identifiers,
expected answers, hidden evaluator state, credentials, or speculative claims.
